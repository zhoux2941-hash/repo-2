# 项目介绍

本项目是我个人工作学习中，整理的一些简单的echarts图表demo，后期会在持续深入更新



## 项目概况

- 技术栈: Vue 3 + TypeScript + Vite + ECharts + Element Plus

- 项目类型: 数据可视化图表展示项目

- 主要功能: 折线图、柱状图、饼图、地图等图表展示
  

## 拷贝代码

git：git clone https://gitee.com/tao-j-l/vue3_e-charts.git

zip（推荐）：点击-克隆/下载



## 运行

> 推荐使用   node^ >=18.0.0   npm^ >=8.0.0

```javascript
# 初始化项目,下载依赖包
npm install

# 启动开发环境
npm run dev
```
