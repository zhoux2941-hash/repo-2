# 项目介绍

本项目是我个人工作学习中，整理的一些简单的echarts图表demo，后期会在持续深入更新



项目使用 vite^5.0.8 搭建。

项目主要使用 vue^3.3、vue-router作为基础建设，使用了一些element-plus做基础UI布局。

可视化图例主要使用

- echarts



## 运行

```javascript
# 初始化项目,下载依赖包
npm install

# 启动开发环境
npm run dev
```



###### 推荐使用 node^ >=18.0.0，npm^ >=8.0.0
